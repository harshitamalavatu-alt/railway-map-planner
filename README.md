# Railway Map Planner

A command-line route optimization and graph traversal tool that models rail transit networks as weighted graphs and finds the optimal path between stations using Dijkstra's Algorithm.

## Features
- **Weighted Graph Network Model**: Stations as graph nodes and bidirectional tracks as weighted edges.
- **Shortest Path Optimization**: Priority queue (min-heap) implementation of Dijkstra's Algorithm for shortest distance (km) and fastest travel duration (minutes).
- **Interactive Route Queries**: Interactive terminal interface to explore stations, search codes, and inspect route itineraries with ASCII transit maps.
